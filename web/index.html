Getting a pad ready

Details

  

  

  

  

  

    Firmware update
    
A firmware package (firmware.zip, from make firmware) has an update
      for each pad; the page takes this pad's, restarts the pad into its updater, writes it and
      starts it.

    

    

    

      
      
    

    
    

  

  

    Link tests
    
Write sizes: sends the most data a command takes, in 20- and 96-byte writes, as
      settings for a target that does not exist (nothing is staged), and checks the pad parsed all of it.
      Updater round trip: restarts the pad into its updater, connects again without the chooser,
      reads it, and reboots it back into its app (the link ends).
